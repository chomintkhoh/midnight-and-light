阅读训练 / Reading Practice

练习方法 / How to practise：先看问题，再带着问题阅读。遇到真正影响理解的词，才打开词语帮助。
Read the questions first, then read with a purpose. Open vocabulary help only when a word blocks your understanding.

请选择阅读程度。
Choose a reading level.

① 先看问题 / Read the Questions First

先不要看文章。读一遍问题，注意每题在问什么。
Do not read the passage yet. Read the questions and notice what each one is asking.

题目关键词 / Question Keywords
② 带着问题阅读 / Read with a Purpose

先自己阅读。只有当词语真的让你看不懂句子时，才按词语帮助。
Read by yourself first. Open vocabulary help only when a word truly blocks the sentence.

词语帮助 / Vocabulary Help

需要时才打开。
Open only when needed.

③ 回答问题 / Answer the Questions

回到文章找证据，不要只凭感觉选择。
Return to the passage and look for evidence. Do not answer by guessing alone.

④ 完整读一次 / Read the Whole Passage Again

题目完成后，再完整读一次文章，把刚才理解的词语和内容连起来。
After answering, read the whole passage once more and connect the vocabulary with the full meaning.
